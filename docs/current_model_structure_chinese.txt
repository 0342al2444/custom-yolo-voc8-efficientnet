当前自定义 YOLO 模型结构
========================

实验名称:
voc8_current_efficientnetb0_deeper_img960

总结:
这是我们目前最好的自定义 YOLO 风格目标检测模型。它使用预训练 EfficientNet-B0 作为 backbone，使用 FPN + PAN neck，加入 Gold-YOLO-lite 的 gather-distribute 融合结构，并且使用四个 anchor-free 检测头、DFL 边框预测和训练时辅助检测头。

========================
1. 模型基本信息
========================

- 模型类型: 自定义 YOLO 风格目标检测模型
- Backbone: 使用 ImageNet 预训练的 EfficientNet-B0
- 输入图片大小: 960 x 960
- 类别数量: 8
- 类别: person, car, dog, cat, bus, train, bicycle, aeroplane
- 总参数量: 11,683,044
- 推理时实际使用的参数量，不包含辅助头: 9,972,944
- 检测尺度: stride 4, stride 8, stride 16, stride 32
- 实验名称: voc8_current_efficientnetb0_deeper_img960

========================
2. 整体流程
========================

输入图片
  -> EfficientNet-B0 预训练 backbone
  -> 多尺度特征 P2, P3, P4, P5
  -> FPN 自上而下 neck
  -> PAN 自下而上 neck
  -> Gold-YOLO-lite gather-distribute 融合
  -> 四个检测头
  -> 解码边框和计算置信度
  -> NMS
  -> 最终检测结果

========================
3. 输入
========================

输入 tensor 的形状是:

[B, 3, 960, 960]

其中:
- B = batch size
- 3 = RGB 三个颜色通道
- 960 x 960 = resize 和 letterbox 后的图片大小

因为 backbone 是预训练模型，所以输入使用 ImageNet 风格的 normalization。

========================
4. 主干网络: EfficientNet-B0
========================

Backbone 会提取四个不同分辨率的特征图。

对于 960 x 960 输入:

P2:
- Stride: 4
- 形状: [B, 24, 240, 240]
- 作用: 高分辨率特征图，适合小物体

P3:
- Stride: 8
- 形状: [B, 40, 120, 120]
- 作用: 中小物体

P4:
- Stride: 16
- 形状: [B, 112, 60, 60]
- 作用: 中大型物体

P5:
- Stride: 32
- 形状: [B, 1280, 30, 30]
- 作用: 大物体和高层语义特征

Backbone 参数量:
4,007,548

========================
5. EfficientNet-B0 阶段流程
========================

大致的 EfficientNet-B0 特征流程:

输入:
[B, 3, 960, 960]

Stem:
[B, 32, 480, 480]

前面的 MBConv blocks:
[B, 16, 480, 480]

P2 输出:
[B, 24, 240, 240]

P3 输出:
[B, 40, 120, 120]

P4 输出:
[B, 112, 60, 60]

P5 输出:
[B, 1280, 30, 30]

========================
6. P5 降通道和 SPPF
========================

EfficientNet-B0 输出的 P5 通道数很多:

P5:
[B, 1280, 30, 30]

模型先降低通道数:

1280 -> 192

然后使用 SPPF，也就是 Spatial Pyramid Pooling Fast。
SPPF 可以让模型看到更大的范围，同时不改变特征图尺寸。

输出:
[B, 192, 30, 30]

========================
7. FPN 自上而下 Neck
========================

FPN 会把深层的强语义信息传回高分辨率特征图。

FPN4:
- P5 上采样: [B, 192, 30, 30] -> [B, 192, 60, 60]
- 和 P4 拼接: [B, 112, 60, 60]
- 拼接后形状: [B, 304, 60, 60]
- C2fLite 输出: [B, 128, 60, 60]

FPN3:
- FPN4 降通道并上采样: [B, 128, 60, 60] -> [B, 96, 120, 120]
- 和 P3 拼接: [B, 40, 120, 120]
- 拼接后形状: [B, 136, 120, 120]
- C2fLite 输出: [B, 96, 120, 120]

FPN2:
- FPN3 降通道并上采样: [B, 96, 120, 120] -> [B, 64, 240, 240]
- 和 P2 拼接: [B, 24, 240, 240]
- 拼接后形状: [B, 88, 240, 240]
- C2fLite 输出: [B, 64, 240, 240]

========================
8. PAN 自下而上 Neck
========================

PAN 会把高分辨率细节再传回深层特征图。

PAN3:
- FPN2 下采样: [B, 64, 240, 240] -> [B, 96, 120, 120]
- 和 FPN3 拼接: [B, 96, 120, 120]
- 拼接后形状: [B, 192, 120, 120]
- C2fLite 输出: [B, 96, 120, 120]

PAN4:
- PAN3 下采样: [B, 96, 120, 120] -> [B, 128, 60, 60]
- 和 FPN4 拼接: [B, 128, 60, 60]
- 拼接后形状: [B, 256, 60, 60]
- C2fLite 输出: [B, 128, 60, 60]

PAN5:
- PAN4 下采样: [B, 128, 60, 60] -> [B, 192, 30, 30]
- 和 P5 context 拼接: [B, 192, 30, 30]
- 拼接后形状: [B, 384, 30, 30]
- C2fLite 输出: [B, 192, 30, 30]

Base neck 输出:
- N2: [B, 64, 240, 240]
- N3: [B, 96, 120, 120]
- N4: [B, 128, 60, 60]
- N5: [B, 192, 30, 30]

Neck 参数量:
2,409,664

========================
9. Gold-YOLO-Lite 融合
========================

Gold-YOLO-lite 融合让不同尺度的特征互相交流。

Gather 步骤:
先把所有特征图 resize 到 P3 的大小，也就是 120 x 120。

N2:
[B, 64, 240, 240] -> [B, 96, 120, 120]

N3:
[B, 96, 120, 120] -> [B, 96, 120, 120]

N4:
[B, 128, 60, 60] -> [B, 96, 120, 120]

N5:
[B, 192, 30, 30] -> [B, 96, 120, 120]

然后拼接:
[B, 96, 120, 120] x 4 -> [B, 384, 120, 120]

融合:
Conv 384 -> 96
C2fLite fusion blocks

融合后的全局特征:
[B, 96, 120, 120]

Distribute 步骤:
把融合后的特征再送回每一个尺度。

送回 N2:
[B, 96, 120, 120] -> [B, 64, 240, 240]

送回 N3:
[B, 96, 120, 120] -> [B, 96, 120, 120]

送回 N4:
[B, 96, 120, 120] -> [B, 128, 60, 60]

送回 N5:
[B, 96, 120, 120] -> [B, 192, 30, 30]

Gold fusion 参数量:
1,137,216

========================

融合后，最终用于检测的特征图是:

P2 检测头:
- Stride: 4
- 形状: [B, 64, 240, 240]
- 预测点数量: 57,600

P3 检测头:
- Stride: 8
- 形状: [B, 96, 120, 120]

P4 检测头:

========================
11. 检测头
========================

每个尺度都有一个检测头。

每个检测头预测:
- box_raw
- objectness
- class logits

设置:
- num_classes = 8
- reg_max = 16
- 每个边框方向的 DFL bins = 17
- 边框四个方向 = left, top, right, bottom
- 边框输出通道数 = 4 x 17 = 68
- Objectness 通道数 = 1
- Class 通道数 = 8

输出形状:

P2:
- box: [B, 68, 240, 240]
- obj:  [B, 1, 240, 240]
- cls:  [B, 8, 240, 240]

P3:
- box: [B, 68, 120, 120]
- obj:  [B, 1, 120, 120]
- cls:  [B, 8, 120, 120]

P4:
- box: [B, 68, 60, 60]
- obj:  [B, 1, 60, 60]
- cls:  [B, 8, 60, 60]

P5:
- box: [B, 68, 30, 30]
- obj:  [B, 1, 30, 30]
- cls:  [B, 8, 30, 30]

主检测头参数量:
2,418,516

========================
12. 检测头深度
========================

========================
13. 辅助检测头
========================

辅助检测头只在训练时使用。
它们帮助 backbone 和 neck 学到更强的特征。
推理时不会使用辅助检测头。

Aux P2:
- 输入: Gold fusion 之前的 base N2
- 额外 refine blocks: 3

Aux P3:
- 输入: Gold fusion 之前的 base N3
- 额外 refine blocks: 2

Aux P4:
- 输入: Gold fusion 之前的 base N4
- 额外 refine blocks: 0

Aux P5:
- 输入: Gold fusion 之前的 base N5
- 额外 refine blocks: 0

辅助检测头参数量:
1,710,100

========================
14. Anchor-Free 边框预测
========================

模型是 anchor-free。
它不使用预设 anchor boxes。

每个预测点预测四个距离:
- left
- top
- right
- bottom

这个预测点可以理解成边框的中心参考点。
模型预测边框从这个点向四个方向延伸多远。

边框解码:
x1 = center_x - left_distance
y1 = center_y - top_distance
x2 = center_x + right_distance
y2 = center_y + bottom_distance

========================
15. DFL 边框预测
========================

DFL 是 Distribution Focal Loss。
模型不是直接预测一个距离数字，而是预测 17 个 bins 上的分布。

因为:
reg_max = 16
bins = 0, 1, 2, ..., 16

对于边框的每一个方向，DFL 会把这个分布转换成更平滑的连续距离。

这样可以提高边框定位质量。

========================
16. 置信度计算
========================

对于每一个预测:

objectness = sigmoid(obj_logit)
class_score = sigmoid(cls_logit)
final_score = objectness x class_score

final_score 就是最后的 confidence score。

========================
17. NMS
========================

解码边框之后，模型会使用 NMS。

当前 eval 设置:
- 同类别 NMS IoU threshold: 0.5
- 每张图最多检测数量: 100
- 是否进行跨类别重复框抑制: True
- 重复框 IoU threshold: 0.9
- 尺寸相似度 threshold: 0.95
- 中心点距离 threshold: 0.05

这会去掉重复框，保留最好的框。

========================
19. 训练 Loss
========================

模型训练时主要有这些 loss:

Classification loss:
- 帮助模型预测正确类别。

Objectness loss:
- 帮助模型判断某个点是否有物体。

Box loss:
- 帮助模型预测更准确的边框坐标。

DFL loss:
- 帮助模型预测更准确的边框距离分布。

Auxiliary loss:
- 在训练时帮助前面的特征学得更好。

模型使用 quality-aware objectness。
这表示匹配质量更好的预测框会得到更强的 objectness target。

========================
21. 优点和弱点
========================

优点:
- 边框质量强
- mAP50-95 明显高于 YOLOv8n
- 大物体检测效果好
- 低 confidence 下 recall 很高
- conf = 0.10 时 practical precision 很好

弱点:
- 小物体检测仍然比较弱
- 中等物体也比大物体弱
- 模型比 YOLOv8n 更大
- 推理成本比 YOLOv8n 更高

========================
22. 最终简短总结
========================

当前模型是:

EfficientNet-B0 预训练 backbone
+ FPN
+ PAN
+ Gold-YOLO-lite 融合
+ 四尺度 anchor-free 检测头
+ DFL 边框预测
+ 训练时辅助检测头

它在严格边框定位质量上强于 YOLOv8n，特别是 mAP50-95。
它目前最大的弱点仍然是小物体和中等物体检测。
